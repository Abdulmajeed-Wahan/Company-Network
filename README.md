# Company-Network
Company Network Design and Implementation using Cisco Packet Tracer.
🏢 Company Network Design & Implementation

Cisco Packet Tracer | Network Engineering | Network Security

👨‍💻 Project Overview

This project demonstrates the design and implementation of a small company network using Cisco Packet Tracer.

The network is structured into three departments using VLAN segmentation to improve network organization, traffic management, and communication between departments.

🌐 Network Topology

"Company Network Topology" (images/network-topology.jpg)

🏬 Department Network Design

Department| VLAN| IP Network
Admin / IT| 10| 192.168.10.0/24
Finance / HR| 20| 192.168.20.0/24
Customer Service / Reception| 30| 192.168.30.0/24

⚙️ Network Implementation

1. VLAN Configuration

Logical network segmentation was implemented to separate company departments.

"VLAN Configuration" (images/vlan-configuration.jpg)

2. DHCP Configuration

DHCP was configured to provide automatic IP address assignment to network devices.

"DHCP Configuration" (images/dhcp-configuration.jpg)

3. Wireless Network

Wireless Access Points were configured to provide connectivity for wireless devices.

"Wireless Configuration" (images/wireless-configuration.jpg)

4. Inter-VLAN Routing

Routing configuration enables communication between different departmental VLANs.

🧪 Network Testing

Connectivity was tested using the ICMP Ping command.
