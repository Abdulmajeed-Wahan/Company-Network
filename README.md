# Company-Network
Company Network Design and Implementation using Cisco Packet Tracer.
Company Network Design and Implementation

📌 Project Overview

This project demonstrates the design and implementation of a company network using Cisco Packet Tracer.

🖥️ Network Devices

- Cisco 2621 Router
- Cisco 2960 Switch
- 3 Desktop PCs
- 3 Wireless Devices
- 3 Network Printers

🔧 Technologies & Configuration

- VLAN Configuration
- DHCP Configuration
- Inter-VLAN Routing
- Network Segmentation
- IP Addressing
- Connectivity Testing

🏢 Departments

- Admin / IT
- Finance / HR
- Customer Service / Reception

🛠️ Tools

- Cisco Packet Tracer
- Cisco IOS CLI

🎯 Project Objectives

- Improve network organization.
- Separate departments using VLANs.
- Enable communication between authorized networks.
- Provide automatic IP address assignment using DHCP.
